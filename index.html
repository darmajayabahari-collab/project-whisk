Remix images with AI

Paste image URLs for subject, scene, and style — Project Whisk blends them into something new.

How to use
  1. Paste image URLs into Subject, Scene, and/or Style — preview loads automatically.
  2. Add optional extra instructions (e.g. "flat vector, white background, minimal").
  3. Pick a style pill and set batch count (1–8 images at once).
  4. Click Generate — images appear as they load.
  5. Hover any result to download or save to history.
  6. Every session is logged automatically. Click Export .txt to download prompts for ComfyUI.
